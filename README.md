# Auto Post Content AI & Topic Generator

Plugin WordPress cerdas dan tangguh untuk riset topik AI, penulisan artikel SEO mendalam (1 atau 2 bahasa ID & EN), funneling piramida TOFU-MOFU-BOFU, injeksi internal link silo otomatis menuju Target Landing Page (Money Page), serta penjadwalan otomatis yang fleksibel.

## Fitur Utama

- **Riset Topik AI Terarah**: Riset ide topik sesuai kategori spesifik dan klasifikasi funnel (TOFU/MOFU/BOFU) dengan judul natural (45-65 karakter, bebas kata klise AI).
- **Target Landing Page (Money Page Booster)**: Daftarkan URL penawaran/produk utama per kategori dengan variasi keyword anchor. Plugin otomatis menyuntikkan backlink internal dari artikel baru.
- **Silo Architecture Isolation**: Kategori SEO hanya saling menautkan artikel sejenis dan landing page SEO, mencegah kanibalisasi topik.
- **Bilingual (ID & EN)**: Dukungan 1 bahasa atau 2 bahasa otomatis dengan adaptasi English yang alami untuk SEO global.
- **Auto Schedule Natural**: Pilihan posting 1x hingga 24x sehari dengan opsi jam acak alami (07:00-22:00) atau jam tetap terjadwal.
- **One-Click Update via GitHub Release**: Pembaruan plugin otomatis dengan 1 klik langsung dari GitHub Release tanpa perlu upload ZIP berulang kali.
- **Modern UI/UX Pro Max**: Desain antarmuka bersih, cepat, responsif, dan mudah digunakan di WordPress Admin.

## Persyaratan Sistem

- PHP: 8.3 ke atas
- WordPress: 6.0 ke atas
- Akun / Gateway 9Router (OpenAI-compatible)
